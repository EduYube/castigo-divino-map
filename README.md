# El Atlas de los Nuevos Dioses

Aplicación web para explorar un mapa interactivo de Faerûn y consultar notas de la campaña **Castigo Divino** mediante marcadores, categorías y etiquetas.

## Estado

Proyecto en fase de preparación de la Beta 0.1. Consulta [`docs/project-status.md`](docs/project-status.md) para conocer el estado actual.

## Objetivos de la Beta 0.1

- Navegación por el mapa con zoom y desplazamiento.
- Marcadores y fichas de campaña.
- Búsqueda por nombre.
- Categorías y filtros.
- Etiquetas múltiples por nota o marcador.
- Resaltado de todos los elementos asociados a una etiqueta.
- Enlaces directos a lugares y filtros.
- Interfaz responsive.
- Despliegue automático con GitHub Pages.

## Stack previsto

- Vite
- TypeScript
- Leaflet
- Vitest
- Playwright
- ESLint y Prettier
- GitHub Actions
- GitHub Pages

## Flujo de trabajo

1. Toda unidad relevante de trabajo parte de una GitHub Issue.
2. Cada Issue se desarrolla en una rama independiente.
3. Cada Issue se trabaja en un chat nuevo dentro del proyecto de ChatGPT.
4. Los cambios se integran mediante pull request.
5. GitHub es la fuente de verdad del código, decisiones y estado.

Consulta [`docs/working-agreement.md`](docs/working-agreement.md) para ver las reglas completas.

## Repositorio privado

El contenido puede incluir contexto de campaña. No debe publicarse ningún secreto narrativo ni recurso sin licencia sin revisión explícita.
