# Alcance de producto — Beta 0.1

## Visión

Crear un atlas web rápido y accesible para que director y jugadores consulten lugares y conocimiento descubierto de la campaña sobre un mapa interactivo de Faerûn.

## Usuarios

- Director de juego: mantiene el contenido público de campaña.
- Jugadores: exploran, buscan y relacionan información descubierta.

## Funciones imprescindibles

1. Visualizar y navegar por un mapa base de Faerûn.
2. Mostrar marcadores con fichas de información.
3. Buscar elementos por nombre y alias.
4. Clasificar por categorías.
5. Asignar varias etiquetas normalizadas a cada elemento.
6. Filtrar por etiqueta, resaltar coincidencias y atenuar el resto.
7. Abrir una etiqueta desde una ficha.
8. Compartir estado mediante URL, incluyendo lugar o etiqueta activa.
9. Funcionar en escritorio y móvil.
10. Desplegar automáticamente una beta reproducible.

## Etiquetas

Las etiquetas usarán identificadores estables en minúsculas y kebab-case, por ejemplo `seguidores-skade`. Los textos visibles podrán evolucionar sin romper enlaces.

## Privacidad

La beta solo contendrá información apta para jugadores. Marcar un registro como oculto en JavaScript no protege secretos: el contenido privado no debe formar parte del artefacto publicado.

## No objetivos de la beta

Autenticación, permisos por usuario, edición desde navegador, base de datos remota, línea temporal, rutas y gestión de secretos.

## Criterio de éxito

Un jugador puede abrir la web desde móvil, localizar un lugar o una etiqueta en pocos segundos y compartir un enlace que reproduce esa selección.
